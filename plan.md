Project Plan: Floating UI E-commerce Frontend
1. Project Overview
- A modern, responsive e-commerce frontend built with a Floating UI Component architecture. The design focuses on elevation, soft shadows, and independent layers to create a spatial, interactive user experience.
- use alignUI for UI components

- Primary Theme Color: #405bff (Royal Blue)

- Design Philosophy: Atomic Design (Maximum component reusability), Floating Layers, and Minimalist Interfaces.

2. Design System & Style Guide
Visual Language
Elevation: Use multi-layered box-shadow instead of borders to define boundaries.

Corner Radius: High rounding (e.g., 12px to 20px) for a friendly, organic feel.

Backdrop: Subtle use of backdrop-filter: blur() for floating overlays and navigation bars.
